Installing one

These apps install the same way Plane Games does. Chrome may say the file might be harmful. It shows this for app files that do not come from Google Play. Choose Download anyway. Open the downloaded file, allow your browser to install apps if Android asks, and if Google Play Protect steps in, choose More details, then Install anyway.

Each app has its own website with its release notes, privacy policy and terms, and its own place to report a problem.
